## What to build

An authoritative server-side sitting state machine in `IAttemptEngine` that governs macro-skill progression, adaptive unit locking (`UNIT_LOCKED_SANDBOX`), hybrid task-group sub-timers (`HYBRID_GROUP_LOCKED`), post-audio review countdowns (`AUDIO_PLUS_CHECK`), and wall-clock deadline enforcement across all certificates.

1. **Macro-Linearity & Zero Time Rollover (`ActiveSkillId`):** Enforces strict progression across skills (e.g., Listening ➔ Reading ➔ Writing) in `strict_exam` mode. Remaining time is calculated against an absolute wall-clock deadline (`Remaining = max(0, PhaseDeadlineAt - CurrentWallClock)`), immune to browser tab throttling or system sleep. Advancing early or expiring permanently locks the preceding skill and discards unused time with zero rollover.
2. **Micro-Phase Locking by `NavigationMode` & `TimerPolicyJson`:**
   - **`UNIT_LOCKED_SANDBOX` (`ActiveUnitNumber`):** Allows free review within Unit 1; confirming transition permanently locks Unit 1 (`ActiveUnitNumber = 2`) and rejects any subsequent writes to Unit 1 questions.
   - **`HYBRID_GROUP_LOCKED` (`ActiveGroupId`):** Enforces a shared wall-clock pool for the initial question group (e.g., 8 minutes for TOEIC Writing Q1–5) followed by individual non-rollover sub-deadlines and permanent lock upon advancing across subsequent tasks (e.g., Q6 10m ➔ Q7 10m ➔ Q8 30m).
   - **`AUDIO_PLUS_CHECK`:** Transitions automatically from audio playback into the configured post-audio review countdown (`checkTimeSec`, e.g., 120s for IELTS Listening) before auto-locking and submitting the skill.

## Acceptance criteria

- [ ] `IAttemptEngine` verifies that answer saves and draft updates only apply to the currently active `ActiveSkillId`, `ActiveUnitNumber`, and `ActiveGroupId`; writes to locked skills, units, or groups throw an invalid domain operation exception.
- [ ] Transitioning between skills, adaptive units (`UNIT_LOCKED_SANDBOX`), or locked task groups (`HYBRID_GROUP_LOCKED`) permanently locks the preceding phase and discards remaining time (zero rollover).
- [ ] `AUDIO_PLUS_CHECK` sections initiate the configured `checkTimeSec` review window upon audio completion and auto-lock when `PhaseDeadlineAt` expires.
- [ ] Wall-clock deadlines determine remaining seconds server-side, and client timers sync against this server authority.
- [ ] Integration tests in `AttemptEngineTests.cs` verify server-side rejection of writes to expired/locked skills, adaptive units, and hybrid task groups.
