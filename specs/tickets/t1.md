## What to build

Core database schema foundations (`docs/database-schema.sql`) and EF Core model configurations supporting the **6 Certificate-Agnostic Rule Axes**, the **Section Authoring Blueprint**, and the **11 Official Question Components** across IELTS on Computer (Academic/GT), TOEIC L&R Standard CBT, TOEIC Multi-Stage Adaptive CAT, TOEIC Speaking & Writing, VSTEP, and any custom administrator-defined certificate.

This eliminates hardcoded certificate-code branching (`CASE c.Code WHEN 'IELTS'...`) from SQL triggers and C# services, providing the persistent data-driven attributes required by the Certificate Wizard (#116, #120), Dynamic Exam Studio (#117, #118, #121), and Sitting/Scoring Engine (#108–#114, #119) while preserving existing credit ledger, audit triggers, weakness analysis views, and composite certificate foreign keys.

## Acceptance criteria

- [ ] **Axis 1 (`Certificates`):** Adds `ScoreAggregationRule` (`sum`, `avg_half_step`, `avg_whole`, `independent`) and optional `PresetCode` (`ielts_academic`, `ielts_gt`, `toeic_lr_std`, `toeic_lr_cat`, `toeic_sw`, `vstep`, `custom`) so `trg_Attempts_TotalMatchesSkills` and `trg_Attempts_TotalMatchesSkills_OnAttempt` evaluate aggregation rules dynamically without hardcoding `c.Code`.
- [ ] **Operating Mode (`Exams`):** Adds `DeliveryMode` (`strict_exam`, `practice`).
- [ ] **Axes 2, 3, 4, 5 & 6 (`Sections` Sitting & Authoring Blueprint):** Adds `ScoreWeight` (`DECIMAL(5,2) NOT NULL DEFAULT 1.0`), `NavigationMode` (`FULL_SANDBOX`, `UNIT_LOCKED_SANDBOX`, `AUDIO_DRIVEN`, `SYSTEM_PACED_AUTO`, `HYBRID_GROUP_LOCKED`), `TimerPolicyJson`, `LayoutType` (`STANDARD_VERTICAL`, `SPLIT_HORIZONTAL`, `MEDIA_CARD`, `CLUSTER_3`), `OptionCount` (`INT NOT NULL DEFAULT 4`), `ClusterSize` (`INT NOT NULL DEFAULT 1`), `UnitCount` (`INT NOT NULL DEFAULT 1`), `HideOptionText` (`BIT NOT NULL DEFAULT 0`), `RequirePassage` (`BIT NOT NULL DEFAULT 0`), `RequireAudio` (`BIT NOT NULL DEFAULT 0`), `RequireImage` (`BIT NOT NULL DEFAULT 0`), `RequiredKeywordCount` (`INT NOT NULL DEFAULT 0`), `AllowedComponentTypesJson` (`NVARCHAR(MAX)`), and `ToolsConfigJson` (`NVARCHAR(MAX)`).
- [ ] **Adaptive Units (`QuestionGroups`):** Adds `UnitNumber` (`INT NOT NULL DEFAULT 1`, supporting `1` or `2` for multi-stage adaptive routing).
- [ ] **11 Question Components (`Questions` & `Options`):** Extends `QuestionType` (`mcq`, `mcq_3`, `multi_select`, `inline_completion`, `dropdown`, `drag_drop`, `free_response`), adds `MaxSelections`, `AllowNumber`, `AcceptedAnswersJson`, and `RequiredKeywords` (for mandatory prompt keywords); relaxes `CK_Questions_Words` so `inline_completion` can specify `MaxWords`; scopes `UX_Options_OneCorrect` so `multi_select` questions can hold multiple `IsCorrect = 1` options.
- [ ] **Multi-Component Responses (`AttemptAnswers` & `PracticeAnswers`):** Adds `ResponseText` (`NVARCHAR(MAX) NULL`) and `SelectedOptionIdsJson` (`NVARCHAR(MAX) NULL`) alongside `SelectedOptionId` while preserving `IsCorrect (0/1)` for `vw_UserCategoryAccuracy` and `vw_UserSectionAccuracyAll`.
- [ ] **Authoritative Sitting State (`ExamAttempts`):** Adds `ActiveSkillId`, `ActiveUnitNumber`, `ActiveGroupId`, `AuthorizationCode`, `PhaseDeadlineAt`, `LastAudioOffsetMs`, and `CandidateNotesJson` (for tokenized highlights/notes persistence).
- [ ] EF Core model configurations declare `HasTrigger(...)` for all modified tables with triggers, preventing `OUTPUT`-clause save failures.
- [ ] `docs/seed-demo.sql` seeds complete 6-axis blueprints and representative 11-component questions for IELTS, TOEIC Standard, TOEIC CAT, TOEIC S&W, and VSTEP.
- [ ] `dotnet test tests/Services.Tests` executes and passes cleanly against real LocalDB.
