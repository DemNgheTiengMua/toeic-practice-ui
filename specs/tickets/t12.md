**Step 05 of 15** — Phase 2: Certificate-Driven Authoring & Ingest

## What to build

Upgraded batch ingestion pipeline (`QuestionImportManifest`, `QuestionImportService`, `ExportExamPackageAsync`) and downloadable Certificate-driven manifest templates supporting all official and custom certificates and all 11 question components.

Extends the canonical ingest manifest format (`ADR-0007`) so authors can upload `.zip` / `.json` packages, download a pre-structured `.json` skeleton generated dynamically from any Certificate's section blueprint (#116), or export existing exams losslessly. Supports `deliveryMode`, group `unitNumber`, multi-select options with `maxSelections`, completion `acceptedAnswers` with `maxWords` and `allowNumber`, matching dropdown/drag-and-drop items, and mandatory `requiredKeywords`.

## Acceptance criteria

- [ ] `ImportManifest` and `QuestionImportService` dynamically load the target Certificate's persisted section blueprints (#116) and validate every imported section, group, and question against that section's `ExpectedQuestionCount`, `OptionCount`, `ClusterSize`, `AllowedComponentTypesJson`, `RequirePassage`, `RequireAudio`, `RequireImage`, and `RequiredKeywordCount`.
- [ ] Admins can download a pre-structured `manifest-template.json` dynamically generated from any Certificate's blueprint (including custom certificates created in #116) so external authors have the exact section codes, allowed question types, option counts, and slot structures pre-filled.
- [ ] `ExportExamPackageAsync` exports all new exam, group, and 11-component question fields losslessly so exported packages re-import cleanly.
- [ ] Updated sample packages in `docs/samples/` and integration tests in `QuestionImportServiceTests.cs` pass 100%.
