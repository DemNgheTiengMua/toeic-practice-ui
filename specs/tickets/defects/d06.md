## Execution Order

**Defect remediation 6 of 8 — Dead practice hint control**

## What to build

Asking for a hint in a practice session actually shows the question's hint text. The control disappears once used, the used-hint marker appears, and the text is the hint authored for that question.

## Why it broke

Every seeded question has a populated hint, yet activating the control only hides the button and lights the 'hint used' badge — the hint text is never written into the page.

## Acceptance criteria

- [ ] Activating `Show hint` reveals the question's hint text.
- [ ] The hint control is hidden after use and the used-hint marker is shown.
- [ ] The revealed text matches the hint stored for that question.
- [ ] A question with no authored hint shows no hint control.
- [ ] The keyboard shortcut and the on-screen control produce the same result.
- [ ] WebMVC test asserts hint text is present in the practice take DOM for a seeded question.

## Blocked by

None (can start immediately).
