## Execution Order

**Defect remediation 8 of 8 — Practice UI polish and stale DOM**

## What to build

The practice sidebar's filter pills fit their card without pushing the page wider than the viewport, practice stimulus copy references the session's own question numbers, and moving between practice questions clears the previous question's controls from the DOM so no stale answer widget can be interacted with.

## Why it broke

Pills overflow past the right viewport edge (page scrolls to 1280px in a 1262px viewport), practice copy still says 'Questions 7 through 9' inside a 4-question session, and the previous question's radios persist in the DOM on component questions.

## Acceptance criteria

- [ ] The filter pills fit within the sidebar card at desktop width with no horizontal page scroll.
- [ ] The saved-questions pill is fully visible and not clipped.
- [ ] Filtering by all, incorrect and saved still narrows the question grid correctly.
- [ ] Stimulus copy references the current session's question numbers rather than the source exam's global numbering.
- [ ] Navigating from one question to the next removes the previous question's answer controls from the DOM.
- [ ] Multi-select, inline completion, dropdown and drag-and-drop practice items still capture and grade answers correctly after the cleanup.
