`docs/specs/sitting-room-navigation-and-practice-qol-defects.md`

## Execution Order

**Defect remediation 7 of 8 — Unreachable transcript, duplicated rewind**

## What to build

A practice question that has a transcript offers a working transcript toggle; a question without one offers nothing. The five-second rewind control lives inside the audio toolbar instead of floating beneath the audio card, so the player reads as one control cluster.

## Why it broke

The transcript toggle is hidden on every listening practice question, and a stray rewind button renders outside the player. Both are documented QoL features the manual plan expects to be usable.

## Acceptance criteria

- [ ] A listening practice question with a transcript shows the transcript toggle and the drawer expands and collapses.
- [ ] A question with no transcript shows no transcript toggle.
- [ ] The rewind control renders inside the audio toolbar alongside the existing player controls.
- [ ] No duplicated rewind control appears outside the toolbar.
- [ ] Rewind still clamps at the question's audio start boundary.
- [ ] WebMVC test asserts a transcript-less question renders no transcript control.

## Blocked by

None (can start immediately).
