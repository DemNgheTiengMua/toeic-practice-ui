## Execution Order

**Defect remediation 2 of 8 — Blocking dead-end in multi-skill sittings**

## What to build

When a candidate answers the final question of a skill, the primary action becomes an enabled control that finishes the current skill and starts the next one, instead of a permanently disabled `Next phase starts when time expires`. Using it opens the existing confirmation surface, calls the skill transition endpoint, and lands the candidate on the first question of the next skill with a fresh phase countdown. A single-skill exam, and a two-skill exam whose first skill holds only one question, both remain completable.

## Why it broke

Reproduced on `ETS 2024 - Test 1` (exam 1) and `Cambridge IELTS 18 — Academic Test 1` (exam 6). Exam 6 is completely unwalkable: its only Listening question is also the last, so Reading never unlocks.

## Acceptance criteria

- [ ] On the last question of a skill the primary control is enabled and labelled so the candidate knows it advances to the next skill.
- [ ] Activating it requires the documented confirmation, then moves the candidate to the first question of the next skill.
- [ ] After advancing, the previous skill's questions are shown as locked and the new skill's questions are enterable.
- [ ] The phase countdown restarts from the next skill's duration rather than continuing the previous skill's clock.
- [ ] An exam with a single Listening question and a single Reading question can be completed end to end.
- [ ] The disabled `Next phase starts when time expires` state no longer appears anywhere in the sitting room.
- [ ] Timer expiry still auto-submits or advances as a fallback when the candidate never uses the control.
- [ ] Service test covers a two-question, two-skill exam: one transition makes the second skill's question enterable.
