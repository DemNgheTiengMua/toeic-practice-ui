## What to build

The **Audio-Driven, Clustered & Multi-Stage Adaptive CAT Sitting Workspace** (`Take.cshtml` and sitting modules), driven dynamically by the section blueprint's `NavigationMode` (`AUDIO_DRIVEN`, `UNIT_LOCKED_SANDBOX`), `HideOptionText`, `OptionCount`, and `ClusterSize`.

Powers TOEIC Listening & Reading (both 200-question Standard CBT and 90-question Multi-Stage Adaptive CAT) as well as any custom certificate configured with audio-paced or adaptive unit rules:
1. **Audio-Driven Pacing & Masked Stimulus Cards (`AUDIO_DRIVEN`, `HideOptionText`, `OptionCount`, `ClusterSize`):**
   - When `HideOptionText = true` and `RequireImage = true` (e.g., TOEIC Part 1), displays the photograph and 4 radio buttons `(A)–(D)` while masking option text until post-exam review.
   - When `HideOptionText = true` and `OptionCount = 3` (e.g., TOEIC Part 2), displays the question number and 3 radio buttons `(A)–(C)` while masking stem and option text.
   - When `ClusterSize = 3` (e.g., TOEIC Parts 3 & 4), renders clusters of 3 questions simultaneously on a single card synchronized to the audio slice.
   - When `NavigationMode = AUDIO_DRIVEN`, disables backward navigation and free palette jumping during active audio playback.
2. **Reading Review Screen & Multi-Stage Adaptive CAT Routing (`UNIT_LOCKED_SANDBOX`):**
   - Provides an interactive Reading **Review Screen Modal** featuring 3 quick-filter actions: *Jump to First Unanswered*, *Review Only Unanswered*, and *Review Only Flagged*.
   - When `NavigationMode = UNIT_LOCKED_SANDBOX` (e.g., TOEIC CAT), allows free navigation within **Unit 1**; clicking **Finish Unit 1** opens an irreversible lock confirmation modal, calls `AttemptEngine` to lock `ActiveUnitNumber = 1`, and loads the **Unit 2** adaptive question set.

## Acceptance criteria

- [ ] Sections with `HideOptionText = true` mask option/stem text during sitting; `OptionCount = 3` renders 3 choices `(A–C)` and `OptionCount = 4` renders 4 choices `(A–D)`.
- [ ] Sections with `ClusterSize = 3` render 3 questions simultaneously per screen card.
- [ ] Sections with `NavigationMode = AUDIO_DRIVEN` disable backward navigation and free question jumping during strict exams.
- [ ] The Review Screen modal provides working quick-filter actions for unanswered and flagged questions.
- [ ] Sections with `NavigationMode = UNIT_LOCKED_SANDBOX` present a confirmation modal at the end of Unit 1, permanently lock Unit 1 upon confirmation, and load Unit 2.
- [ ] Submitting a Standard CBT or Adaptive CAT sitting produces calibrated 10–990 scaled scores via the `#120` scoring engine.
