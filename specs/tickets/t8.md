## What to build

The **Automated Speaking Pacer Sitting Workspace** (`Take.cshtml` audio/recording state machine, decoupled from Writing per `AGENTS.md` Invariant #6), driven dynamically by the section blueprint's `NavigationMode = SYSTEM_PACED_AUTO` and `TimerPolicyJson = ITEM_FIXED` (`PrepSeconds`, `ResponseSeconds`).

Powers TOEIC Speaking (11 questions / ~20 minutes), VSTEP Speaking, and any custom certificate configured with automated speaking timers:
1. **Automated Prep ➔ Beep ➔ Record ➔ Auto-Advance State Machine (`SYSTEM_PACED_AUTO`):**
   - For each speaking item, automatically sequences through:
     1. **Preparation Phase:** Counts down `PrepSeconds` (`15s` / `30s` / `45s` per question blueprint).
     2. **Audible Beep Cue:** Plays a clear audio beep tone when `PrepSeconds` reaches `00:00`.
     3. **Active Recording Phase:** Automatically starts `MediaRecorder` and counts down `ResponseSeconds` (`15s` / `30s` / `45s` / `60s`) with a live waveform/level indicator.
     4. **Auto-Capture & Advance:** Stops recording at `00:00`, uploads the audio blob in the background, and automatically advances to the next question without requiring manual "Next" clicks.
2. **Post-Section Recorded Audio Verification Screen:**
   - Upon completing the final speaking item (e.g., Question 11 in TOEIC Speaking), presents a verification screen where the candidate can play back and confirm that their recorded audio clips are intact before final submission to the AI grading queue (`IAiGradingProcessor`).

## Acceptance criteria

- [ ] Sections with `NavigationMode = SYSTEM_PACED_AUTO` automate the `Prep Countdown ➔ Audible Beep ➔ Recording Countdown ➔ Auto-Upload & Advance` loop using each question's `PrepSeconds` and `ResponseSeconds`.
- [ ] Manual forward/backward navigation is disabled during the automated speaking flow.
- [ ] Following the final speaking question, candidates are presented with the recorded audio verification screen before final submission.
- [ ] Confirmed speaking submissions enqueue cleanly for `IAiGradingProcessor` without any coupling to `WritingPracticeService` (`AGENTS.md` Invariant #6).
- [ ] Automated tests verify the state machine transitions (`Prep ➔ Beep ➔ Record ➔ Advance ➔ Verify`) and audio upload persistence.
