## What to build

The unified **11-Component Objective Evaluator & Weighted Score Conversion Engine** in `IAttemptEngine` / `ScoreConversionService`, paired with **Step 4 of the Linear Guided Certificate Wizard** and its interactive **Live Score Preview Calculator**.

Consolidating all objective grading and score conversion rules here (`AGENTS.md` Invariant #7) ensures that every sitting workspace (#111–#114) and Practice Drilling (#119) calls one authoritative evaluation seam rather than duplicating grading logic across UI slices:
1. **Unified 11-Component Objective Evaluator (`AttemptEngine`):**
   - Evaluates standard single-choice (`mcq`, `mcq_3`), multi-select checkbox (`multi_select` exact set match against `SelectedOptionIdsJson`), inline text/table completion (`inline_completion` case-insensitive exact match against `AcceptedAnswersJson` with whitespace normalization and strict `MaxWords` / `AllowNumber` enforcement awarding `0` points when limits are exceeded), dropdown matching (`dropdown`), and drag-and-drop (`drag_drop`).
   - Evaluates mandatory prompt keyword compliance (`RequiredKeywords` lemma/stem check verifying plural/tense-invariant word presence).
2. **Step 4 of Certificate Wizard — Plain-Language Score Aggregation & Section Weights:**
   - Choose `ScoreAggregationRule` (*"Sum of skill scores — e.g. TOEIC 10–990"*, *"Average rounded to nearest 0.5 band — e.g. IELTS 0–9.0 / VSTEP 0–10.0"*, *"Average rounded to nearest whole number"*, or *"Report each skill independently — e.g. TOEIC S&W 0–200"*).
   - Set relative `ScoreWeight` multipliers between sections/tasks within a skill (e.g., $\text{RoundHalf}((\text{Task1} \times 1.0 + \text{Task2} \times 2.0) / 3.0)$ for Writing).
3. **Dynamic Raw-to-Scaled Conversion Tables & Live Score Preview Calculator:**
   - Upgrades `ScoreConversionService` and `ScoreConversion.cshtml` to dynamically size raw score ceilings from the certificate's section configuration (`ExpectedQuestionCount`, e.g., 40 for IELTS L/R, 45 for TOEIC CAT, 100 for TOEIC Standard) while enforcing monotonicity and non-overlapping bands.
   - Provides an interactive sandbox calculator where the educator types sample candidate performance and immediately sees the calculated scaled skill scores, weighted task totals, overall score, and matched CEFR/Band badge in real time.

## Acceptance criteria

- [ ] `IAttemptEngine` accurately evaluates all objective question components (`mcq`, `mcq_3`, `multi_select`, `inline_completion` with `MaxWords`/`AllowNumber`, `dropdown`, `drag_drop`) and `RequiredKeywords` lemma checks, setting `IsCorrect (0/1)`.
- [ ] `IAttemptEngine` and `ScoreConversionService` compute skill and total scores dynamically using the certificate's `ScoreWeight` and `ScoreAggregationRule` (`sum`, `avg_half_step`, `avg_whole`, `independent`).
