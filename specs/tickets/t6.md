## What to build

The **Controlled Writing Sitting Workspace & AI Grading Integration** (`Take.cshtml`, `WritingPracticeService` / `IAiGradingProcessor`), driven dynamically by the section blueprint's `ToolsConfigJson` (`showWordCount`, `disableSpellCheck`, `allowKeyboardCutPaste`, `showOnScreenCutPaste`, `confirmOnNext`) and `NavigationMode` (`FULL_SANDBOX` vs `HYBRID_GROUP_LOCKED`).

Cleanly encapsulates all **Writing** examination behaviors in a single domain slice (decoupled from Speaking per `AGENTS.md` Invariant #6), powering IELTS Writing (Task 1 & Task 2), VSTEP Writing, TOEIC Writing (Questions 1–8), and any custom certificate's Writing skill:
1. **Standard Academic/General Writing Mode (`allowKeyboardCutPaste = true`, `showWordCount = true`, `disableSpellCheck = true` — e.g. IELTS & VSTEP Writing):**
   - Multi-line plain text editor with real-time word counter updating on every keystroke, browser `spellcheck="false"`, `autocorrect="off"`, `autocomplete="off"`, and free task switching between Task 1 (`MinWords = 150`, `ScoreWeight = 1.0`) and Task 2 (`MinWords = 250`, `ScoreWeight = 2.0`).
   - Attaches diagnostic under-length warning flags when a submitted essay falls below the question's `MinWords` threshold.
2. **Strict Toolbar & Hybrid Sub-Timer Writing Mode (`allowKeyboardCutPaste = false`, `showOnScreenCutPaste = true`, `NavigationMode = HYBRID_GROUP_LOCKED` — e.g. TOEIC Writing Q1–8):**
   - Intercepts and blocks keyboard `Ctrl+C`, `Ctrl+V`, and `Ctrl+X` events while rendering an explicit on-screen editing toolbar with functional `[Cut]`, `[Paste]`, `[Undo]`, and `[Redo]` buttons.
   - Displays mandatory prompt keyword badges (`RequiredKeywords`) on photo-sentence tasks (Questions 1–5) and integrates the `#120` lemma keyword checker into submission evaluation.
   - Enforces the `HYBRID_GROUP_LOCKED` sub-timers: a shared 8-minute pool with free navigation across Questions 1–5, followed by individual countdowns (10m for Q6, 10m for Q7, 30m for Q8) with confirmation modals (`confirmOnNext = true`) that permanently lock each preceding question.

## Acceptance criteria

- [ ] When `showWordCount = true` and `disableSpellCheck = true`, the Writing editor updates word counts on every keystroke and disables browser spellcheck/autocorrect/autocomplete.
- [ ] Under-length writing submissions (`WordCount < MinWords`, e.g., <150 for Task 1 or <250 for Task 2) record a diagnostic length penalty flag and weight tasks using `Sections.ScoreWeight` (#120).
- [ ] When `allowKeyboardCutPaste = false` and `showOnScreenCutPaste = true`, keyboard `Ctrl+C`/`Ctrl+V`/`Ctrl+X` are blocked and on-screen `[Cut]`, `[Paste]`, `[Undo]`, and `[Redo]` toolbar buttons operate on the editor selection.
- [ ] When `NavigationMode = HYBRID_GROUP_LOCKED`, Questions 1–5 share an 8-minute pool while Questions 6, 7, and 8 enforce individual timers (10m, 10m, 30m) and confirmation modals that permanently lock the previous question.
- [ ] Questions with `RequiredKeywords` display the required keyword pairs and invoke the lemma keyword checker upon evaluation.
